# MAKER LAB with AI — 배경음악(BGM) 버전

## 시작 방법
Windows에서는 `start_windows.bat`를 실행하고 `http://localhost:8000`을 여세요. Python 3 설치가 필요합니다.
직접 실행하려면 `python run_server.py`를 입력합니다.

## 음악 추가
1. `music/` 폴더에 `wooden-marble.mp3` 등 MP3 파일을 저장합니다.
2. 홈페이지를 새로고침합니다. 서버 실행 중에는 음악 파일 목록이 자동으로 갱신됩니다.
3. 곡 제목을 바꾸려면 `music/tracks.json`에 파일명을 키로 지정합니다.
4. 목록은 파일명 오름차순으로 재생되며 마지막 곡 이후 처음으로 돌아갑니다. 순서를 정하려면 `01-intro.mp3`, `02-maker.mp3`처럼 파일명에 번호를 붙이세요.

## 자동재생 안내
홈페이지 접속 시 음악 재생을 시도합니다. 다만 **Chrome·Safari·모바일 브라우저는 소리 있는 자동재생을 차단할 수 있습니다.** 이 경우 오른쪽 아래의 `▶`를 한 번 누르면 재생됩니다. 모든 기기에서 강제 자동재생은 보장할 수 없습니다. 재생 후에는 메뉴 이동 중에도 음악이 이어집니다.

## 폴더
- `gallery/` : 제작 작품 이미지 (유일한 작품 갤러리 폴더)
- `gallery/works.json` : 작품 제목과 설명
- `images/` : 장비·교수 프로필 및 일반 이미지
- `music/` : 배경음악 MP3 등
- `music/tracks.json` : 곡 제목 설정

`galley` 오타 폴더는 제거했습니다. 예전에 해당 폴더에 저장한 실제 이미지가 있다면 **삭제 전에 `gallery/`로 이동**하세요.

## 정적 웹호스팅
음악과 이미지 파일을 추가한 후 `python refresh_images.py`를 실행하여 목록 JSON 파일을 생성한 뒤 전체 폴더를 서버에 업로드하세요.
