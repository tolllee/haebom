# MAKER LAB with AI — 홈페이지 고도화 버전

## 폴더 구성
- `index.html`: 메인 HTML
- `css/style.css`: 모든 화면 디자인 및 PC 3열 / 태블릿 2열 / 모바일 1열
- `js/app.js`: 메뉴 이동, 검색, 장비 상세, 이미지 갤러리 등
- `images/`: 사진 넣는 폴더
- `이미지_파일명_가이드.md`: **어떤 사진을 어떤 이름으로 저장해야 하는지** 설명
- `run_server.py`: 이미지를 자동 탐색하는 로컬 실행 서버
- `start_windows.bat`: 윈도우에서 실행할 때 더블클릭
- `refresh_images.py`: 정적 웹호스팅 업로드용 이미지 목록 생성기
- `images-manifest.json`: 자동 생성/갱신되는 목록 파일

## 가장 쉬운 실행
1. Python 3을 설치합니다.
2. `images/`에 `profile.jpg`, `fdm.jpg` 등 사진을 넣습니다.
3. `start_windows.bat`를 더블클릭합니다.
4. 브라우저 주소창에 `http://localhost:8000`을 입력합니다.
5. 사진을 추가하고 새로고침하면 자동 표시됩니다.

이미지 이름은 반드시 `이미지_파일명_가이드.md`를 확인하세요.

## 현재 상태
교육용 샘플 콘텐츠를 기반으로 한 반응형 프로토타입입니다. 실제 센터 보유 장비와 사진은 관리자가 확인해야 합니다.
